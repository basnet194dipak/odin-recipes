# Odin Recipes

<!-- brief description about what the current project is -->
A simple recipes website  built as part of [The Odin Project curriculum](https://www.theodinproject.com/paths) following the [The Odin Project - Recipes](https://www.theodinproject.com/lessons/foundations-recipes)

## Project structure:
```text
odin-recipes
    ├── README.md
    ├── images
    │   ├── ChickenEnchiladas.png
    │   ├── Lasagna.png
    │   └── fff.webp
    ├── index.html
    └── recipes
        ├── ChickenEnchiladas.html
        ├── ChickenNoodleCasserole.html
        └── lasagna.html 
```

## Project Requirements:

### Iteration 1: Initial Structure

- Create an `index.html` file inside the `odin-recipes` directory.
- Add the standard HTML boilerplate.
- Add an `<h1>` heading containing **Odin Recipes**.

### Iteration 2: Recipe Page

- Create a `recipes` directory.
- Create an HTML page for a recipe.
- Include the standard HTML boilerplate.
- Add an `<h1>` containing the recipe name.
- Link to the recipe page from `index.html`.
- Add a link from the recipe page back to the home page.

### Iteration 3: Recipe Content

Each recipe page should contain:

- A free image of the finished dish.
- A **Description** heading and description paragraph(s).
- An **Ingredients** heading with an unordered list.
- A **Steps** heading with an ordered list of preparation steps.

### Iteration 4: Additional Recipes

- Add two more recipe pages.
- Keep the same layout for all recipe pages.
- Add links to all recipes from `index.html`.
- Organize the recipe links using an unordered list.

    - Open `index.html` in a web browser.
